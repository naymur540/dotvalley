Instructions

For configuring OTP in Firebase you must create a Firebase project first. If you have not created any project for your application yet, please create one.

Now go to the Firebase console and follow the instructions below:

  1. 1. Go to your Firebase project.
  2. 2. Navigate to the Build menu from the left sidebar and select Authentication.
  3. 3. Get started with the project and go to the Sign-in method tab.
  4. 4. From the Sign-in providers section, select the Phone option.
  5. 5. Ensure you enable the method phone and press Save.
