Google Recaptcha Instructions
  1. 1. To get site key and secret key Go to the Credentials page (Click here)
  2. 2. Add a label (Ex: abc company)
  3. 3. Select reCAPTCHA v3 as ReCAPTCHA Type
  4. 4. Select sub type: I'm not a robot checkbox
  5. 5. Add Domain (For ex: demo.6amtech.com)
  6. 6. Check in Accept the reCAPTCHA Terms of Service
  7. 7.Press Submit
  8. 8. Copy Site Key and Secret Key Paste in the input field below and Save.
Google Recaptcha Instructions

  3. Select reCAPTCHA v3 as ReCAPTCHA Type
  4. Select sub type: I'm not a robot checkbox
  5. Add Domain (For ex: demo.6amtech.com)

  7. Press Submit
